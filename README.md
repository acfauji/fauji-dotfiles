# Fauji Dotfiles

Personal development environment configuration for security research and development.

## Contents

- `.bashrc` / `.zshrc` — Shell configuration
- `.vimrc` / `.nvim` — Editor configuration
- `scripts/` — Utility scripts
- `tools/` — Tool installation scripts
- `aliases/` — Shell aliases and functions

## Setup

```bash
git clone https://github.com/acfauji/fauji-dotfiles.git ~/.dotfiles
cd ~/.dotfiles
./install.sh
```
